# Projeto de Banco de Dados - Petshop 🐾

Este repositório contém a estrutura de um banco de dados relacional desenvolvido em SQL para gerenciar as operações de um petshop (clientes, animais, serviços e atendimentos)[cite: 1, 2, 3].

---

## 📂 Estrutura dos Arquivos

O projeto está dividido nos seguintes scripts SQL:

1. **`criação petshop.sql`**: Script responsável por criar o banco de dados `petshop_db` e todas as suas tabelas (`clientes`, `animais`, `servicos` e `atendimentos`) com suas respectivas chaves primárias e estrangeiras[cite: 1].
2. **`DML petshop.sql`**: Script de inserção de dados fictícios (*Data Manipulation Language*), povoando cada tabela com registros variados para testes[cite: 2].
3. **`DQL petshop.sql`**: Script contendo consultas avançadas (*Data Query Language*), incluindo filtros, ordenações, funções de agregação (`COUNT`, `SUM`, `AVG`, `MAX`, `MIN`) e junções (`JOIN`)[cite: 3].

---

## 🚀 Como Executar

1. Abra o seu SGBD MySQL (como MySQL Workbench, DBeaver ou PhpMyAdmin).
2. Execute primeiro o arquivo **`criação petshop.sql`** para estruturar o banco[cite: 1].
3. Em seguida, execute o arquivo **`DML petshop.sql`** para popular as tabelas[cite: 2].
4. Por fim, utilize o arquivo **`DQL petshop.sql`** para testar as consultas e visualizar os relatórios[cite: 3].
